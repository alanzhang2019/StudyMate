### 关键口诀（必背）

```
字符串读入:
  cin >> s       → 读到空格停止, 读单词
  getline(cin, s) → 读整行, 含空格
  getline(cin, s, ',') → 读到逗号停止
字符 vs 字符串:
  'a' 是字符, "a" 是字符串 (长度为 1)
  char c = 'a'; string s = "abc";
下标: C++ 数组从 0 开始, 但题目可能从 1 开始, 看清楚
边界: n=0, n=1, n=max 都要单独手算
```
