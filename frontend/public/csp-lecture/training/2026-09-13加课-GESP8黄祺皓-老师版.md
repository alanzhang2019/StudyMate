### 考点 1：堆（priority_queue）

**两件必背**：
1. `priority_queue<int>` **默认大根堆**（top 是最大元素）
2. 改小根堆：`priority_queue<int, vector<int>, greater<int>>`

**为什么默认大根堆**：STL 容器适配器的默认比较器是 `less<T>`，对 int 来说就是从大到小。

**自定义 cmp**（结构体排序）：
```cpp
struct Node { int d, u; };
struct cmp { bool operator()(const Node& a, const Node& b) const { return a.d > b.d; } };
priority_queue<Node, vector<Node>, cmp> pq;
```

**典型陷阱**：
- 忘写 `vector<int>` 第三参数 → 编译错
- `greater` 反过来写 `less` → 变成大根堆但以为是小根
- 自定义 cmp 写错方向（`a.d > b.d` 是小根，`a.d < b.d` 是大根）

**变体题**：
```cpp
priority_queue<int, vector<int>, greater<int>> pq;
pq.push(3); pq.push(1); pq.push(2);
cout << pq.top();  // 输出 1
```

**祺皓要点**：必拿。让他现场口述 3 遍小根堆声明。

### 考点 2：并查集（路径压缩 + 按秩合并）

**两大优化**：
1. **路径压缩**：`fa[x] = find(fa[x])`，**find 时**把路径上所有点直接挂到根
2. **按秩合并**：合并时**把小树挂到大树**下，减少树高

**两者的作用**：
- 路径压缩：影响**单次 find** 的时间（O(n) → O(log n)）
- 按秩合并：影响**整体树高**（不按秩也能 O(log n)，按秩后接近 O(α(n))）

**典型陷阱**：
- 只写 `if (fa[x] != x) find(fa[x])` 而不写 `fa[x] = find(fa[x])` → 没压缩
- `unite` 写错成 `fa[x] = y` 而不先 `find` → 没找到根
- 按秩合并**不影响正确性**（题目 4 答案），只是常数优化

**变体**：
```cpp
// 不路径压缩
int find(int x) { return fa[x] == x ? x : find(fa[x]); }
// 时间 O(n)，链状数据会 TLE
```

**祺皓要点**：必拿。让他默写 `fa[x] == x ? x : fa[x] = find(fa[x])` 3 遍。

### 考点 3：Dijkstra 最短路

**算法要点**：
- **只能处理非负权图**（题目 5 答案 A）
- 优先队列版本复杂度 **O((n+m) log n)**
- 负权图必须用 Bellman-Ford 或 SPFA（8 级不考）

**核心代码（必背 12 行）**：
```cpp
struct Edge { int to, w; };
vector<Edge> g[MAXN];
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
vector<int> dis(n+1, INT_MAX);
dis[s] = 0; pq.push({0, s});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dis[u]) continue;  // ⭐关键：跳过过期节点
    for (auto& e : g[u]) {
        if (dis[e.to] > dis[u] + e.w) {
            dis[e.to] = dis[u] + e.w;
            pq.push({dis[e.to], e.to});
        }
    }
}
```

**典型陷阱**（题目 7 答案 A）：
- **漏 `if (d > dis[u]) continue;`** → TLE（一个节点可能被多次入队，要跳过）
- `pair<int,int>` 默认大根堆，所以 `greater<>` 才能小根
- 忘写 `dis[s] = 0` → 起点 dis 是 INT_MAX，所有松弛都失败

**祺皓要点**：必拿。`continue;` 这行是 GESP 8 级 T1 的"送命题"。

### 考点 4：Floyd 多源最短路

**核心公式**：
```cpp
for (int k = 1; k <= n; k++)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```

**复杂度 O(n³)**，所以 **n ≤ 400**（题目 8 答案 B）。

**典型陷阱**：
- `k` 循环必须**最外层**（DP 顺序要求）
- 不可与 Dijkstra 混用（Floyd 是多源，Dijkstra 是单源；稠密图 Dijkstra 也要 O(n²)）
- `d[i][i]` 应初始化为 0
- 无边初始化为 INF

**变体**：
- 已知任意两点最短路 → Floyd
- 单源最短路 + 稀疏图 → Dijkstra
- 负权 + 单源 → Bellman-Ford

**祺皓要点**：理解即可。考场上**优先用 Dijkstra**（Floyd 太慢且常数大）。

### 考点 5：最小生成树（Kruskal）

**核心思路**：边按权重排序，从小到大加，**不形成环**就加（用并查集判环）。

**核心代码**：
```cpp
struct Edge { int u, v, w; };
sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) { return a.w < b.w; });
int ans = 0, cnt = 0;
for (auto& e : edges) {
    if (find(e.u) != find(e.v)) {  // 不成环
        unite(e.u, e.v);
        ans += e.w;
        if (++cnt == n - 1) break;  // n-1 条边就够
    }
}
```

**Kruskal vs Prim**：
- Kruskal：O(m log m)，稀疏图
- Prim：O(n²)，稠密图

**祺皓要点**：选做。模板虽然短，但需要并查集 + 排序，**容易写错**。

### 考点 6：0/1 背包 vs 完全背包

**核心区别 = 内层循环方向**：
- **0/1 背包**（每件最多 1 次）：**内层倒序**（题目 9 答案 B）
- **完全背包**（每件无限次）：**内层正序**（题目 10 答案 A）

**为什么**：
- 倒序时，`dp[v - w[i]]` 还是上一轮 i-1 的结果（**不包含当前物品**），保证每件只选 1 次
- 正序时，`dp[v - w[i]]` 已经是本轮 i 的结果（**可能包含当前物品**），允许重复选

**0/1 模板（必背）**：
```cpp
vector<int> dp(V+1, 0);
for (int i = 1; i <= N; i++) {
    for (int v = V; v >= w[i]; v--) {  // 倒序！
        dp[v] = max(dp[v], dp[v - w[i]] + v[i]);
    }
}
cout << dp[V];
```

**祺皓要点**：必拿。让他**口述**为什么 0/1 倒序（防同物多次选），完全正序（允许重复）。

### 考点 7：区间 DP 入门

**状态定义**（题目 11 答案 A）：`dp[l][r]` = 区间 [l, r] 的最优解。

**经典例题**：石子合并
```cpp
for (int len = 2; len <= n; len++) {  // 枚举长度
    for (int l = 1; l + len - 1 <= n; l++) {
        int r = l + len - 1;
        dp[l][r] = INF;
        for (int k = l; k < r; k++) {  // 枚举分割点
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + sum[r] - sum[l-1]);
        }
    }
}
```

**典型陷阱**：
- 区间长度从 2 开始（len=1 时无意义）
- 分割点 k 从 l 到 r-1（k=r 时右区间空）
- 初始化 `dp[i][i] = 0`（单石子合并代价 0）

**祺皓要点**：放弃。8 级 T3 可能考，但 D 队学员**不推荐**。

### 考点 8：二叉树遍历（前/中/后/层）

**核心结论**（GESP 8 级 2024-12 T2 必考）：
- **前 + 中** → 唯一确定（题目 12 答案 A）
- **后 + 中** → 唯一确定（题目 13 答案 A）
- **前 + 后** → **不能**唯一确定（题目 14 答案 B，反例：根 1 左 2 / 根 1 右 2）
- 已知一种 + **层序** → 唯一确定

**反例（前+后不唯一）**：
```
   1          1
  /            \
 2              2
前序 12 后序 21    前序 12 后序 21   （两个不同树，前+后序列相同）
```

**构造方法**（前+中）：
1. 前序第 1 个是根
2. 在中序中找到根的位置，分出左子树和右子树
3. 递归处理

**祺皓要点**：必拿。让他背 3 个结论（前+中、后+中、前+后）。

### 考点 9：Trie 字典树

**结构**：26 字母树，每节点 26 个孩子指针。

**节点定义**：
```cpp
struct Node {
    int next[26];  // 子节点编号，0 表示无子节点
    int cnt;       // 以该节点结尾的单词数
};
vector<Node> trie(1);  // 根节点
```

**插入**（题目 15 答案 A 表示"子节点指针"）：
```cpp
void insert(string s) {
    int u = 0;
    for (char c : s) {
        int v = c - 'a';
        if (!trie[u].next[v]) {
            trie[u].next[v] = trie.size();
            trie.push_back({});
        }
        u = trie[u].next[v];
    }
    trie[u].cnt++;
}
```

**典型陷阱**：
- `next[26]` 是**子节点编号/指针**，不是计数或深度
- 区分"单词结尾数"和"前缀数"
- 字符集大小决定数组大小（26 字母就 26，ASCII 就 128）

**祺皓要点**：选做。插入/查询模板较长，**考场上默写风险大**。

### 考点 10：KMP 字符串匹配

**核心**：`next[]` 数组 = **最长相等前后缀长度**（不含自己）。

**模板（必背但 8 级放弃）**：
```cpp
void getnext(string s, int nxt[]) {
    nxt[0] = 0;
    for (int i = 1, j = 0; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) j = nxt[j-1];
        if (s[i] == s[j]) j++;
        nxt[i] = j;
    }
}
```

**典型陷阱**：
- `next[i]` 是**前 i+1 个字符**的最长前后缀，不含自己
- `j = nxt[j-1]` 回退时是 `j-1`（不是 j）
- KMP 本身逻辑长，**8 级不推荐死磕**

**祺皓要点**：放弃。考场上不写 KMP，用 `string::find` 或 `substr` 暴力凑分。

### 考点 11：二分答案

**适用场景**：求"最大值最小"或"最小值最大"的问题，**答案有单调性**。

**模板（必背 3 行）**：
```cpp
int l = L, r = R;
while (l < r) {
    int m = (l + r) / 2;
    if (check(m)) r = m;
    else l = m + 1;
}
cout << l;
```

**典型陷阱**（GESP 8 级 2024-09 T4 经典）：
- `(l + r) / 2` 在 l + r 极大时会溢出，**改成 `l + (r - l) / 2`**
- `check(m)` 函数必须**先写出来再写主程序**
- 求"最小可行"用上面模板；求"最大可行"用对称版本

**祺皓要点**：必拿。让他背 3 行模板。

### 考点 12：时间复杂度分析

**8 级常考**（题目 8 答案 B）：
| 复杂度 | n = 1e5 时的表现 |
|---|---|
| O(1) | 永远秒过 |
| O(log n) | 永远秒过 |
| O(√n) | 317 次，秒过 |
| O(n) | 1e5，秒过 |
| O(n log n) | 1.7e6，1 秒内 |
| O(n√n) | 3e7，1-2 秒 |
| O(n²) | 1e10，**TLE** |
| O(n² log n) | 1e10+，TLE |
| O(n³) | 1e15，**TLE**（n ≤ 400 才能跑） |
| O(2ⁿ) | n ≤ 25 |

**常见判断**：
- 1e5 数据 + 双层循环 → 必 TLE
- 1e3 数据 + 三层循环 → 勉强能跑
- Floyd n ≤ 400 极限（题目 8 答案 B）

**祺皓要点**：必拿。让他背这个分界表。

### 逐题详细解析

**题 1** —— `priority_queue<int>` 默认是**大根堆**（top 是最大）。STL 容器适配器的默认比较器是 `less<T>`，对 int 来说从大到小排序。

**题 2** —— 改小根堆要写**三参数模板**：`priority_queue<int, vector<int>, greater<int>>`。`less` 是大根，`greater` 是小根。

**题 3** —— 路径压缩影响**单次 find 的时间**。不压缩时链状数据（如 `1-2-3-4-...-n`）每次 find 都走到底，时间 O(n)，TLE。**WA、RE、编译错误都不会，只会是 TLE**。

**题 4** —— 按秩合并影响**时间复杂度**（不按秩 O(log n)，按秩接近 O(α(n)) ≈ O(1)）。**不影响正确性**。

**题 5** —— Dijkstra 要求**边权非负**。负权会让"已确定最短路"被后续松弛推翻，Dijkstra 失效。负权图必须用 Bellman-Ford 或 SPFA。

**题 6** —— `priority_queue<pair<int,int>>` 默认**大根堆**（先比 first，比不出再比 second）。所以松弛边 `push({dis[e.to], e.to})` 后 top 是 `dis` 最大的，不是最小的。需要 `greater<>` 才能小根。

**题 7** —— `if (d > dis[u]) continue;` 作用是**跳过过期节点**。一个节点可能被多次入队，pop 出来的 `d` 不一定等于当前 `dis[u]`（可能已经被更短路径更新过）。这种情况说明这次入队的旧路径已经过时，跳过即可。**没这行会 TLE**。

**题 8** —— Floyd 复杂度 O(n³)。n = 1000 时是 1e9 次操作，**TLE**。n = 400 时是 6.4e7 次，约 1 秒内能跑完。所以**适用 n ≤ 400**。

**题 9** —— 0/1 背包**内层倒序**。原因：倒序时 `dp[v - w[i]]` 还是上一轮 i-1 的结果，**不包含当前物品**，保证每件只选 1 次。如果正序，`dp[v - w[i]]` 已经是本轮 i 的结果，**可能包含当前物品**，变成完全背包。

**题 10** —— 完全背包**内层正序**。原因：允许重复选当前物品。正序时 `dp[v - w[i]]` 已经是本轮 i 的结果，**可能包含当前物品**，自然实现"重复选"。

**题 11** —— `dp[l][r]` 表示**区间 [l, r] 的最优解**。这是区间 DP 的标准状态定义。转移枚举分割点 k = l..r-1。

**题 12** —— **前序 + 中序** 可以唯一确定二叉树。前序第 1 个是根，在中序中找到根的位置分出左右子树，递归。

**题 13** —— **后序 + 中序** 同样可以唯一确定。后序最后 1 个是根。

**题 14** —— **前序 + 后序** **不能**唯一确定。反例：根 1 左 2（只有 1 个孩子）vs 根 1 右 2，前序都是 `12`，后序都是 `21`，但两个不同树。

**题 15** —— 26 字母 Trie 节点 `int next[26]` 表示**子节点指针**（子节点在节点数组中的编号）。0 表示无子节点（根节点编号 0，永远存在）。

## 四、4 道模板题 · 详细题解

### 4.1 [P3378 堆](https://www.luogu.com.cn/problem/P3378) 🟨

**题意**：维护一个小根堆，支持插入、查询最小、删除最小、输出大小、合并、删除任意元素。

**思路**：直接用 `priority_queue<int, vector<int>, greater<int>>` 即可。

**标准代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    priority_queue<int, vector<int>, greater<int>> pq;
    while (n--) {
        int op; cin >> op;
        if (op == 1) { int x; cin >> x; pq.push(x); }
        else if (op == 2) cout << pq.top() << "\n";
        else if (op == 3) pq.pop();
    }
}
```

**祺皓验收**：
- 10 min 内 AC
- 闭眼口述 3 遍小根堆声明

**易错点**：
- 忘写 `vector<int>` 第三参数
- `greater` 写错成 `less`
- `top()` 不删，`pop()` 不返回

### 4.2 [P3367 并查集](https://www.luogu.com.cn/problem/P3367) 🟨

**题意**：维护 n 个元素的集合，支持合并和查询是否同集合。

**思路**：标准并查集，**必须路径压缩**（否则链状 TLE）。

**标准代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;
int fa[10005];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
void unite(int x, int y) {
    x = find(x); y = find(y);
    if (x != y) fa[x] = y;
}
int main() {
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++) fa[i] = i;
    while (m--) {
        int z, x, y; cin >> z >> x >> y;
        if (z == 1) unite(x, y);
        else cout << (find(x) == find(y) ? "Y" : "N") << "\n";
    }
}
```

**祺皓验收**：
- 10 min 内 AC
- 默写 `fa[x] == x ? x : fa[x] = find(fa[x])` 3 遍

**易错点**：
- 漏写 `fa[x] = find(fa[x])`（没压缩）
- `unite` 写错成 `fa[x] = y`（没 find 根）
- `fa[10005]` 数组大小不够

### 4.3 [P4779 单源最短路](https://www.luogu.com.cn/problem/P4779) 🟨

**题意**：n 点 m 边有向图（边权正），求 s 到所有点的最短路。

**思路**：Dijkstra + 优先队列 + 邻接表。

**标准代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;
struct Edge { int to, w; };
int main() {
    int n, m, s; cin >> n >> m >> s;
    vector<vector<Edge>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        g[u].push_back({v, w});
    }
    const int INF = 1e9;
    vector<int> dis(n + 1, INF);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    dis[s] = 0; pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dis[u]) continue;  // ⭐跳过过期节点
        for (auto& e : g[u]) {
            if (dis[e.to] > dis[u] + e.w) {
                dis[e.to] = dis[u] + e.w;
                pq.push({dis[e.to], e.to});
            }
        }
    }
    for (int i = 1; i <= n; i++) cout << dis[i] << " ";
    return 0;
}
```

**祺皓验收**：
- 20 min 内 AC（重点盯 `continue;` 那行）
- 默写 2 遍，10:42 抽背

**易错点**（送命题）：
- **漏 `if (d > dis[u]) continue;`** → TLE
- `dis[s] = 0` 忘写
- `pair<int,int>` 默认大根，忘加 `greater<>`
- 边权负数会 WA（Dijkstra 失效）

### 4.4 [P1048 采药](https://www.luogu.com.cn/problem/P1048) 🟨

**题意**：0/1 背包。T 时间内采药，每株药耗时 t[i]、价值 v[i]，求最大价值。

**思路**：0/1 背包 1 维 DP，**内层倒序**。

**标准代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int T, M; cin >> T >> M;
    vector<int> t(M+1), v(M+1);
    for (int i = 1; i <= M; i++) cin >> t[i] >> v[i];
    vector<int> dp(T+1, 0);
    for (int i = 1; i <= M; i++)
        for (int j = T; j >= t[i]; j--)  // 倒序！
            dp[j] = max(dp[j], dp[j - t[i]] + v[i]);
    cout << dp[T] << endl;
    return 0;
}
```

**祺皓验收**：
- 15 min 内 AC
- 口述为什么倒序

**易错点**：
- 内层正序 = 完全背包 = 错
- 漏 `j >= t[i]` 边界
- 答案输出 `dp[T]`（不是 `dp[T-1]`）

### 5.1 [B4001 公交线路](https://www.luogu.com.cn/problem/B4001) 🟧 — **必做（30 min）**

**题意**：n 个公交站，m 条线路（单向），每条线路有权重（时间），求从 s 到 t 的最短时间。

**思路**：**Dijkstra 模板题**。邻接表 + 优先队列 + 路径压缩 = 必拿分题。

**标准代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;
struct Edge { int to, w; };
int main() {
    int n, m, s, t; cin >> n >> m >> s >> t;
    vector<vector<Edge>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        g[u].push_back({v, w});
    }
    const int INF = 1e9;
    vector<int> dis(n + 1, INF);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    dis[s] = 0; pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dis[u]) continue;
        for (auto& e : g[u]) {
            if (dis[e.to] > dis[u] + e.w) {
                dis[e.to] = dis[u] + e.w;
                pq.push({dis[e.to], e.to});
            }
        }
    }
    cout << dis[t] << endl;
    return 0;
}
```

**复盘重点**：
- 建图：单向边 `g[u].push_back({v, w})`
- 初始化 `dis[] = INF`，`dis[s] = 0`
- pq 起始 push `{0, s}`
- `continue;` 跳过过期节点
- 答案输出 `dis[t]`

**祺皓目标**：**11:30 前 AC**（这是 3h 课程最重要的一道题）。

### 5.2 [B4044 闯关](https://www.luogu.com.cn/problem/B4044) 🟧 — **选做（20 min）**

**题意**：n 个景点，m 条路，每条路有权重。从 1 出发，至少访问 k 个景点（含起点），求最短路径。

**思路**：**状态压缩 DP**。`dp[s][v]` = 已访问景点集合为 s、当前在 v 时的最短路径。转移：枚举下一个景点 u（不在 s 中），`dp[s|{u}][u] = min(dp[s|{u}][u], dp[s][v] + dis[v][u])`。

**标准代码（状态压缩版）**：
```cpp
#include <bits/stdc++.h>
using namespace std;
int n, m, K, d[20][20], dp[1<<16][20];
int main() {
    cin >> n >> m >> K;
    memset(d, 0x3f, sizeof(d));
    for (int i = 0; i < n; i++) d[i][i] = 0;
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        u--; v--;
        d[u][v] = min(d[u][v], w);
        d[v][u] = min(d[v][u], w);
    }
    // Floyd 预处理最短路
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
    // 状态压缩 DP
    memset(dp, 0x3f, sizeof(dp));
    for (int i = 0; i < n; i++) dp[1<<i][i] = 0;  // 起点
    for (int s = 0; s < (1<<n); s++) {
        int cnt = __builtin_popcount(s);
        if (cnt > K) continue;  // 超过 K 个
        for (int v = 0; v < n; v++) {
            if (dp[s][v] == 0x3f3f3f3f) continue;
            for (int u = 0; u < n; u++) {
                if (s & (1<<u)) continue;  // 已访问
                int ns = s | (1<<u);
                dp[ns][u] = min(dp[ns][u], dp[s][v] + d[v][u]);
            }
        }
    }
    int ans = 0x3f3f3f3f;
    for (int s = 0; s < (1<<n); s++) {
        if (__builtin_popcount(s) != K) continue;
        for (int v = 0; v < n; v++) ans = min(ans, dp[s][v]);
    }
    cout << ans << endl;
}
```

**复盘重点**：
- 状态：`dp[s][v]` = 已访问集合 s + 当前在 v 的最短路
- 状态数：2ⁿ × n（n ≤ 15 才不爆）
- 转移：枚举下一个未访问的点 u
- Floyd 预处理所有点对最短路（不然每次转移要 Dijkstra）

**祺皓目标**：**看题 5 min 决定是否放弃**。8 级 T1 是状态压缩 DP，**对 D 队学员偏难**，不要死磕。

**保底**：写一个暴力 dfs 拿部分分（只算访问 k 个点的所有排列）。
