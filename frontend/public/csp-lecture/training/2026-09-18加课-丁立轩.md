### 关键口诀（必背）

```
变量类型:
  int a;           // 整数
  double a;        // 实数
  char c;          // 字符
  string s;        // 字符串
  bool b;          // 布尔
循环:
  for (int i = 0; i < n; i++) { ... }  // 0 到 n-1
  while (条件) { ... }                  // 直到条件为假
  do { ... } while (条件);              // 至少执行一次
条件:
  if (条件) { ... }
  else if (条件) { ... }
  else { ... }
  && (与) || (或) ! (非)
```
