### 关键口诀（必背）

```
一维数组:
  int a[100];                  // 静态数组, 大小固定
  vector<int> a(n);            // 动态数组, 大小 n
  for (int i = 0; i < n; i++)  // 遍历: 0 到 n-1
    cout << a[i];
二维数组:
  int a[10][10];
  for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
      cout << a[i][j];
字符串:
  char s[100];                 // 字符数组
  string s;                    // string 类
  s.length() 或 s.size()       // 长度
  s[i]                         // 第 i 个字符
循环:
  for (int i = 0; i < n; i++)  // 0 到 n-1
  while (条件)                  // 直到条件为假
  do { ... } while (条件);      // 至少执行一次
```
