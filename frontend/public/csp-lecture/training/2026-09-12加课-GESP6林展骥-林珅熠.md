### 10:00–10:30 共同段：模板手写

#### 10:05–10:20 链表 + 队列（林展骥主写，林珅熠挑错）

**目标题**：[P1996 约瑟夫问题](https://www.luogu.com.cn/problem/P1996) · 🟨

```cpp
// 林展骥 90 min 内必须能手写 2 遍 (queue 版 + 数组模拟版)
#include <queue>
using namespace std;
int main() {
    int n, m; cin >> n >> m;
    queue<int> q;
    for (int i = 1; i <= n; i++) q.push(i);
    int cnt = 0;
    while (!q.empty()) {
        int x = q.front(); q.pop();
        if (++cnt == m) { cout << x << " "; cnt = 0; }
        else q.push(x);
    }
}
```

**教练要盯**：`queue::empty()` 别写 `q.size() == 0`、循环终止条件别死循环。

#### 10:20–10:30 DFS / BFS 模板（林珅熠主写）

**目标题**：[P1443 马的遍历](https://www.luogu.com.cn/problem/P1443) · 🟨

```cpp
// BFS 八方向模板
int dx[8] = {-2,-2,-1,-1, 1, 1, 2, 2};
int dy[8] = {-1, 1,-2, 2,-2, 2,-1, 1};
queue<pair<int,int>> q;
q.push({x,y}); dis[x][y] = 0;
while (!q.empty()) {
    auto [cx,cy] = q.front(); q.pop();
    for (int k = 0; k < 8; k++) {
        int nx = cx + dx[k], ny = cy + dy[k];
        if (nx<1||nx>n||ny<1||ny>m||dis[nx][ny]) continue;
        dis[nx][ny] = dis[cx][cy] + 1;
        q.push({nx,ny});
    }
}
```

**重点纠正**：林珅熠八方向 `dx/dy` 经常漏 `(-1,2) (1,-2)` 这两组，教练当场拿
铅笔画 8 个点让他补全。
