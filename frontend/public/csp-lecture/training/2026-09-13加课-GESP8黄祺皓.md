### 10:15–10:30 模板 2：并查集

**目标题**：[P3367 并查集](https://www.luogu.com.cn/problem/P3367) · 🟨

```cpp
int fa[10005];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }  // 路径压缩
void unite(int x, int y) {
    x = find(x); y = find(y);
    if (x != y) fa[x] = y;
}
```

**教练要盯**：
- `find` 的**三元表达式写法**祺皓容易写成 `if/else` 然后忘记压缩
- 默写 2 遍，10:25 抽背

### 10:30–10:45 模板 3：Dijkstra 最短路

**目标题**：[P4779 单源最短路](https://www.luogu.com.cn/problem/P4779) · 🟨

```cpp
// 邻接表 + 优先队列版 O((n+m) log n)
struct Edge { int to, w; };
vector<Edge> g[MAXN];
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
vector<int> dis(n+1, INT_MAX);
dis[s] = 0; pq.push({0, s});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dis[u]) continue;  // 关键：过期节点跳过
    for (auto& e : g[u]) {
        if (dis[e.to] > dis[u] + e.w) {
            dis[e.to] = dis[u] + e.w;
            pq.push({dis[e.to], e.to});
        }
    }
}
```

**教练要盯**：
- `if (d > dis[u]) continue;` 这行**很多学员会漏**，结果是 TLE
- `pair<int,int>` 默认**大根堆**，所以 `greater<>` 才能小根
- 默写 2 遍，10:42 抽背

### 10:45–11:00 模板 4：0/1 背包

**目标题**：[P1048 采药](https://www.luogu.com.cn/problem/P1048) · 🟨

```cpp
// 0/1 背包 1 维 DP（内层倒序）
vector<int> dp(V+1, 0);
for (int i = 1; i <= N; i++) {
    for (int v = V; v >= w[i]; v--) {  // 倒序！
        dp[v] = max(dp[v], dp[v - w[i]] + v[i]);
    }
}
cout << dp[V] << endl;
```

**教练要盯**：
- **倒序 vs 正序**是 0/1 背包和完全背包的核心区别，祺皓经常混淆
- 让他**口述**：为什么倒序？（防止同一物品被多次选）
