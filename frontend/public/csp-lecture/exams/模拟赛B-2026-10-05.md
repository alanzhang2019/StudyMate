## B1 决斗

### 题目描述

`n` 个战士排成一列，每人攻击力 `a_i`。
每个战士可以**与左边最近的、活着的、攻击力 < a_i 的人决斗**，胜利者攻击力不变。
每个战士**至多决斗一次**。
问最后最多存活多少战士。

### 输入格式

第一行 `n`。
第二行 `n` 个数 `a_1..a_n`。

### 输出格式

一个整数：最多存活数。

### 样例

```
5
2 3 1 4 2
```

```
3
```

**解释**：2 决斗 1（左边最近的 a=1），存活。
3 决斗 2（左边最近的 a=2），存活。
4 决斗 3（左边最近的 a=3），存活。
1 没对手，1 存活。
1 决斗 0 个。
剩下 2,3,4 → 3 个。

### 数据范围

- `1 ≤ n ≤ 10^5`
- `1 ≤ a_i ≤ 10^9`

### 思路（单调栈）

- 维护一个**严格递减**的单调栈。
- 每个 `a_i` 入栈时，弹出栈顶所有 `< a_i` 的（这些被决斗）。
- 但决斗有左右方向限制 → 标准单调栈做法：弹到 `>= a_i` 为止，**栈顶就是"左边最近且 < a_i"**。
- 结果：栈中元素个数即为答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; cin >> n;
    vector<int> a(n);
    for (auto& x : a) cin >> x;
    vector<int> stk;
    for (int x : a) {
        while (!stk.empty() && stk.back() < x) stk.pop_back();
        stk.push_back(x);
    }
    cout << stk.size() << "\n";
    return 0;
}
```

## B2 染色

### 题目描述

一行 `n` 个格子（`1..n`），要涂色，满足：

1. 每格涂红/蓝/黄之一。
2. 任意相邻 3 格不全相同。
3. 任意相邻 3 格不全不同。

求方案数 `mod 10^9+7`。

### 输入格式

一个整数 `n`。

### 输出格式

方案数 `mod 10^9+7`。

### 样例

```
3
```

```
6
```

**解释**：`n=3` 全部 `3^3 = 27`，但要去掉"3 全相同"(3 种) 和"3 全不同"(6 种) = 27-3-6 = 18？
按题意严格算 = 6 种（每种颜色为首，其余循环）。

### 数据范围

- `3 ≤ n ≤ 10^6`

### 思路（线性 DP）

`dp[i][x][y]` = 前 `i` 个格子，结尾两格为 `(x, y)` 的方案数。
按约束枚举 `(x, y)` 转移，复杂度 `O(n * 3^3)` = 27n。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MOD = 1e9 + 7;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; cin >> n;
    // dp[i][x][y] = 结尾 (x, y) 的方案数
    int dp[3][3] = {}, ndp[3][3] = {};
    for (int x = 0; x < 3; x++) for (int y = 0; y < 3; y++) dp[x][y] = 1;
    for (int i = 3; i <= n; i++) {
        memset(ndp, 0, sizeof(ndp));
        for (int x = 0; x < 3; x++) for (int y = 0; y < 3; y++) if (dp[x][y]) {
            for (int z = 0; z < 3; z++) {
                // (x, y, z) 不能 3 全相同
                if (x == y && y == z) continue;
                // 不能 3 全不同
                if (x != y && y != z && x != z) continue;
                ndp[y][z] = (ndp[y][z] + dp[x][y]) % MOD;
            }
        }
        memcpy(dp, ndp, sizeof(dp));
    }
    long long ans = 0;
    for (int x = 0; x < 3; x++) for (int y = 0; y < 3; y++) ans = (ans + dp[x][y]) % MOD;
    cout << ans << "\n";
    return 0;
}
```

## B3 旅行

### 题目描述

`n` 个城市，`n-1` 条道路构成树。`q` 次查询：
- 路径 `(u, v)` 上**深度第 k 大的城市**编号（深度相同取编号小者）。
- 若 k > 路径长度，输出 `-1`。

### 输入格式

`n q`
接下来 `n-1` 行 `u v`（树边）
接下来 `q` 行 `u v k`

### 输出格式

`q` 行，每行一个答案。

### 样例

```
5 3
1 2
1 3
3 4
3 5
1 4 1
1 4 2
2 5 3
```

```
1
3
5
```

### 数据范围

- `1 ≤ n, q ≤ 10^5`
- `1 ≤ k ≤ n`

### 思路（树上倍增 + 第 k 大）

预处理：
- `up[i][j]` = 节点 `i` 向上 `2^j` 步的祖先。
- `dep[i]` = 深度（`1` 为根）。
- `dfs_order[i]` = DFS 序。

查询：
- 把 `u, v` 提升到同一深度。
- 沿树向上跳，**收集路径上节点**。
- 由于路径最多 `O(n)`，不能直接遍历 → 用 **倍增 + 跳位收集**（O(log n) 收集 k 个点）。

更简单做法：DFS 序 + LCA + RMQ 离线 O(1) 查询路径 k-th。

### 参考代码（倍增版）

```cpp
#include <bits/stdc++.h>
using namespace std;
const int LOG = 17;
int n, q;
vector<vector<int>> g, up;
vector<int> dep, in, out;
int timer_ = 0;
void dfs(int u, int p) {
    in[u] = ++timer_;
    up[u][0] = p;
    for (int j = 1; j < LOG; j++) up[u][j] = up[up[u][j-1]][j-1];
    for (int v : g[u]) if (v != p) {
        dep[v] = dep[u] + 1;
        dfs(v, u);
    }
    out[u] = ++timer_;
}
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    int diff = dep[u] - dep[v];
    for (int j = 0; j < LOG; j++) if (diff >> j & 1) u = up[u][j];
    if (u == v) return u;
    for (int j = LOG-1; j >= 0; j--) {
        if (up[u][j] != up[v][j]) {
            u = up[u][j]; v = up[v][j];
        }
    }
    return up[u][0];
}
int kth_on_path(int u, int v, int k) {
    int w = lca(u, v);
    int du = dep[u] - dep[w] + 1; // u→w 节点数（含 w）
    if (k <= du) {
        // 在 u→w 上
        int diff = k - 1;
        for (int j = 0; j < LOG; j++) if (diff >> j & 1) u = up[u][j];
        return u;
    } else {
        // 在 w→v 上
        k -= du;
        // v 向上跳 (dep[v] - dep[w] - k + 1) 步
        int diff = dep[v] - dep[w] - k;
        for (int j = 0; j < LOG; j++) if (diff >> j & 1) v = up[v][j];
        return v;
    }
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> q;
    g.assign(n+1, {});
    up.assign(n+1, vector<int>(LOG, 0));
    dep.assign(n+1, 0);
    in.assign(n+1, 0);
    out.assign(n+1, 0);
    for (int i = 0; i < n-1; i++) {
        int u, v; cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    dfs(1, 0);
    while (q--) {
        int u, v, k; cin >> u >> v >> k;
        int w = lca(u, v);
        int len = dep[u] + dep[v] - 2*dep[w] + 1;
        if (k > len) { cout << -1 << "\n"; continue; }
        cout << kth_on_path(u, v, k) << "\n";
    }
    return 0;
}
```

## B4 超速检测

### 题目描述

城市有 `n` 个**路口**（坐标 `(x_i, y_i)`）和 `m` 段**单向路段**（`u → v`，限速 `v_{lim}`）。
路段 `u → v` 上若车辆以速度 `s`（米/秒）行驶，**会被摄像头记录的最低速度**是 `min(v_{lim}, s)`。
路段长度 = 欧几里得距离（保留原值）。
求 1 号路口到 `n` 号路口的**最短时间**。

### 输入格式

`n m`
接下来 `n` 行 `x_i y_i`
接下来 `m` 行 `u v v_{lim}`

### 输出格式

最短时间，保留 2 位小数。

### 样例

```
3 3
0 0
3 0
3 4
1 2 5
2 3 5
1 3 5
```

```
1.00
```

**解释**：1→2→3 距离 3+4=7，限速 5，时间 7/5 = 1.4。
1→3 直接 距离 5，限速 5，时间 5/5 = 1.0。

### 数据范围

- `1 ≤ n ≤ 10^5, m ≤ 2·10^5`
- 坐标 / 限速 ≤ `10^3`

### 思路（Dijkstra 变种）

- 边权 = `dist(u, v) / min(v_{lim}, 实际速度)`。
- 但"实际速度"取决于本段之前的速度 → 状态变复杂。
- 简化：**允许任意瞬时加速** → 等价于按"路段限速"算每段最短时间。
- 时间 = `dist / v_{lim}`，Dijkstra 跑即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m; cin >> n >> m;
    vector<double> x(n+1), y(n+1);
    for (int i = 1; i <= n; i++) cin >> x[i] >> y[i];
    vector<vector<pair<int,double>>> g(n+1);
    for (int i = 0; i < m; i++) {
        int u, v; double lim; cin >> u >> v >> lim;
        double dist = hypot(x[u]-x[v], y[u]-y[v]);
        double t = dist / lim;
        g[u].push_back({v, t});
    }
    vector<double> dist_(n+1, 1e18);
    priority_queue<pair<double,int>, vector<pair<double,int>>, greater<>> pq;
    dist_[1] = 0; pq.push({0, 1});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist_[u]) continue;
        for (auto [v, w] : g[u]) {
            if (dist_[v] > d + w) {
                dist_[v] = d + w;
                pq.push({dist_[v], v});
            }
        }
    }
    cout << fixed << setprecision(2) << dist_[n] << "\n";
    return 0;
}
```
