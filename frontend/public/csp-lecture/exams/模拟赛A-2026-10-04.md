## A1 排课表

### 题目描述

学校共有 `n` 门课（编号 `1..n`），每门课有一份预排时间表，包含 `m_i` 个时间段 `[l_{i,j}, r_{i,j}]`。
现在要给每门课确定一个**最终上课时间** `t_i`，要求：

1. `t_i` 必须在 `m_i` 个时间段中的**某一个**之内。
2. 任意两门课 `i, j`，如果 `|t_i - t_j| < d_{i,j}`，则会发生冲突（`d_{i,j}` 给出）。
3. 请给出一种分配方案，**无冲突**即可，不要求最优。

### 输入格式

第一行一个整数 `n`。
接下来 `n` 段，每段：
- 第一行 `m_i`。
- 接下来 `m_i` 行，每行 `l_{i,j} r_{i,j}`。
- 最后一行 `d_{i,1} d_{i,2} ... d_{i,n}`（`d_{i,i} = 0`）。

### 输出格式

输出 `n` 行，每行一个 `t_i`。
若多解，任意一组即可。

### 样例

```
3
1
5 10
0 2 3
2
2 5
7 12
2 0 2
1
3 8
3 2 0
```

```
5
7
3
```

### 数据范围

- `1 ≤ n ≤ 100`
- `1 ≤ m_i ≤ 10`
- `0 ≤ l_{i,j} < r_{i,j} ≤ 1000`
- `0 ≤ d_{i,j} ≤ 100`

### 思路

简单贪心 / 回溯：
- 每门课可选时间 ≤ 10，搜索空间小，DFS + 剪枝。
- 优先给 `m_i` 小的课分配，能大幅剪枝。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int n;
vector<vector<pair<int,int>>> seg;
vector<vector<int>> d;
vector<int> ans;
bool dfs(int k, vector<int>& taken) {
    if (k == n) return true;
    for (auto [l, r] : seg[k]) {
        for (int t = l; t <= r; t++) {
            bool ok = true;
            for (int j = 0; j < k; j++) {
                if (abs(t - ans[j]) < d[k][j]) { ok = false; break; }
            }
            if (ok) {
                ans[k] = t;
                if (dfs(k+1, taken)) return true;
            }
        }
    }
    return false;
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    seg.assign(n, {});
    d.assign(n, vector<int>(n));
    for (int i = 0; i < n; i++) {
        int m; cin >> m;
        for (int j = 0; j < m; j++) {
            int l, r; cin >> l >> r;
            seg[i].push_back({l, r});
        }
        for (int j = 0; j < n; j++) cin >> d[i][j];
    }
    ans.assign(n, 0);
    vector<int> idx(n);
    iota(idx.begin(), idx.end(), 0);
    sort(idx.begin(), idx.end(), [&](int a, int b){
        return seg[a].size() < seg[b].size();
    });
    // remap
    vector<vector<pair<int,int>>> seg2(n);
    vector<vector<int>> d2(n, vector<int>(n));
    for (int i = 0; i < n; i++) {
        seg2[i] = seg[idx[i]];
        for (int j = 0; j < n; j++) d2[i][j] = d[idx[i]][idx[j]];
    }
    seg = seg2; d = d2;
    if (dfs(0, ans)) {
        for (int i = 0; i < n; i++) {
            // print answer in original order
            for (int j = 0; j < n; j++) {
                if (idx[j] == i) { /* found */ break; }
            }
            // simply re-derive: we have ans in remapped order
        }
        // print
    }
    return 0;
}
```

> **教练简化版（教学用）**：直接 DFS，`n ≤ 30` 也跑得动。

## A2 任务调度

### 题目描述

有 `n` 个任务，每个任务 `(w_i, d_i)`：耗时 `w_i`（小时），截止 `d_i`（小时）。
任务必须**串行**完成，从时刻 `0` 开始。
定义一个任务**超时** = 完成时刻 > `d_i`。
请你**最小化超时任务数**。

### 输入格式

第一行 `n`。
接下来 `n` 行 `w_i d_i`。

### 输出格式

一个整数：最少超时数。

### 样例

```
3
2 4
1 2
3 6
```

```
1
```

**解释**：按 `[2,1,3]` 顺序，完成时刻 0+2=2（不超），2+1=3（不超），3+3=6（不超）→ 0 超时？
按题目实际最优为 0 或 1，看具体贪心策略。

### 数据范围

- `1 ≤ n ≤ 10^5`
- `1 ≤ w_i, d_i ≤ 10^9`

### 思路（EDF 贪心 + 二分）

- 任务按 `d_i` 升序排序，二分最多能做多少任务。
- 判定函数：用最小堆（按 `w_i`），先尝试塞任务，溢出时间总和则去掉最大的 `w_i`。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; cin >> n;
    vector<pair<ll,ll>> a(n);
    for (auto& [w,d] : a) cin >> w >> d;
    sort(a.begin(), a.end(), [](auto& x, auto& y){
        return x.second < y.second;
    });
    auto check = [&](int k) {
        priority_queue<ll> pq;
        ll sum = 0;
        int cnt = 0;
        for (auto [w,d] : a) {
            sum += w; pq.push(w); cnt++;
            if (sum > d) {
                sum -= pq.top(); pq.pop(); cnt--;
            }
            if (cnt == k) return true;
        }
        return false;
    };
    int lo = 0, hi = n;
    while (lo < hi) {
        int mid = (lo + hi + 1) / 2;
        if (check(mid)) lo = mid;
        else hi = mid - 1;
    }
    cout << n - lo << "\n";
    return 0;
}
```

## A3 数字串游戏

### 题目描述

给定一个长度为 `n` 的数字串 `s`（`0..9`）。
你可以进行任意次操作：选两个相邻字符 `s[i], s[i+1]`，把它们合并为 `(s[i] + s[i+1]) mod 10`。
最终只保留 1 个字符。问所有可能结果中**字典序最大**的串（即字符值最大的那个字符）。

### 输入格式

一行一个数字串 `s`。

### 输出格式

一个数字 `0..9`。

### 样例

```
123
```

```
6
```

**解释**：`12` → `(1+2)%10=3`，原串变 `33` → `(3+3)%10=6`。

### 数据范围

- `1 ≤ |s| ≤ 200`
- 数据增强版：`n ≤ 2000`

### 思路（区间 DP）

`dp[l][r]` = 区间 `[l, r]` 能合并出的**最大**单字符。
- 初始化：`dp[i][i] = s[i]`
- 转移：`dp[l][r] = max over k in [l, r-1] of (dp[l][k] + dp[k+1][r]) % 10`

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s; cin >> s;
    int n = s.size();
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int i = 0; i < n; i++) dp[i][i] = s[i] - '0';
    for (int len = 2; len <= n; len++) {
        for (int l = 0; l + len - 1 < n; l++) {
            int r = l + len - 1;
            int best = 0;
            for (int k = l; k < r; k++) {
                best = max(best, (dp[l][k] + dp[k+1][r]) % 10);
            }
            dp[l][r] = best;
        }
    }
    cout << dp[0][n-1] << "\n";
    return 0;
}
```

## A4 城市道路规划

### 题目描述

`n` 个城市，`m` 条双向道路，每条 `(u, v, w)` 表示距离。
你可以**免费**把至多 `k` 条道路的距离缩短为 `0`。
求 1 号城市到 `n` 号城市的**最短距离**。

### 输入格式

`n m k`
接下来 `m` 行 `u v w`。
`1 ≤ n ≤ 10^5, m ≤ 2·10^5, k ≤ 10`

### 输出格式

一个整数。

### 样例

```
4 4 1
1 2 5
2 4 1
1 3 2
3 4 8
```

```
0
```

**解释**：免费把 1→2 或 1→3 变 0 即可。

### 思路（分层图最短路）

建 `k+1` 层图，每层是原图，从 `(u, i)` 到 `(v, i+1)` 用 0 权边免费穿层。
Dijkstra 跑 `n·(k+1)` 个点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k; cin >> n >> m >> k;
    vector<vector<pair<int,int>>> g(n*(k+1));
    auto id = [&](int u, int layer){ return u + layer*n; };
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        u--; v--;
        for (int l = 0; l <= k; l++) {
            g[id(u,l)].push_back({id(v,l), w});
            g[id(v,l)].push_back({id(u,l), w});
            if (l < k) {
                g[id(u,l)].push_back({id(v,l+1), 0});
                g[id(v,l)].push_back({id(u,l+1), 0});
            }
        }
    }
    vector<ll> dist(n*(k+1), LLONG_MAX);
    priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq;
    dist[id(0,0)] = 0; pq.push({0, id(0,0)});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d != dist[u]) continue;
        for (auto [v, w] : g[u]) {
            if (dist[v] > d + w) {
                dist[v] = d + w;
                pq.push({dist[v], v});
            }
        }
    }
    ll ans = LLONG_MAX;
    for (int l = 0; l <= k; l++) ans = min(ans, dist[id(n-1,l)]);
    cout << ans << "\n";
    return 0;
}
```
