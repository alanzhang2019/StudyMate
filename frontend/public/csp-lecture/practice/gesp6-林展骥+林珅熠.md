## 二、模板题 6 道（60 min · 默写 + 实战）

> 4 个核心模板 + 2 道变体题。**林展骥**：6 道全做；**林珅熠**：跳过 1, 2 直接做 3-6。

### 2.1 队列 / 约瑟夫（林展骥 必做）

- [P1996 约瑟夫问题](https://www.luogu.com.cn/problem/P1996) 🟨
- **目标**：默写 `queue<int>` 模板 5 行
- **验收**：10 min 内 AC；改用数组模拟版再 AC 1 次

### 2.2 字符串反转（林展骥 必做）

- [P1062 数列反转（自定义）](https://www.luogu.com.cn/problem/P1062) 🟨
- **目标**：手写 reverse，不用 STL `reverse`
- **验收**：10 min 内 AC；边界字符串长度 1 测试通过

### 2.3 栈 / 括号匹配（林展骥 必做，林珅熠 选做）

- [P1739 表达式括号匹配](https://www.luogu.com.cn/problem/P1739) 🟥
- **目标**：用 `stack<char>` 判括号是否匹配 + 处理非法
- **验收**：测试 `(()` `()()` `(()` 三组样例全过

### 2.4 BFS 八方向（共同必做）

- [P1443 马的遍历](https://www.luogu.com.cn/problem/P1443) 🟨
- **目标**：BFS 模板 + 8 方向 `dx/dy` 写对（重点防漏 `(-1,2) (1,-2)`）
- **验收**：15 min 内 AC

### 2.5 0/1 背包（共同必做）

- [P1048 采药](https://www.luogu.com.cn/problem/P1048) 🟨
- **目标**：0/1 背包 1 维 DP（**内层倒序**），能口述状态转移
- **验收**：15 min 内 AC + 默写核心 4 行

### 2.6 LIS 二分优化（林珅熠 主做，林展骥 选看）

- [P1020 导弹拦截](https://www.luogu.com.cn/problem/P1020) 🟨
- **目标**：第一问 O(n²) DP，第二问 `lower_bound` LIS 长度
- **验收**：第一问 AC，第二问理解二分做法即可

## 三、真题模拟 2 道（90 min · 限时）

### 3.1 GESP 2024-09 6 级 T1 · 单调不降序列

- [B3939 单调不降序列](https://www.luogu.com.cn/problem/B3939) 🟨
- **思路**：最长不下降子序列变体，`O(n²)` 即可 AC
- **林展骥目标**：35 min 内 AC（边界 `n=1` 单处理，`f[i] = 1` 初始化）
- **林珅熠目标**：30 min 内 AC
- **复盘重点**：状态定义 `f[i] = 以 a[i] 结尾的最长不下降子序列长度`

### 3.2 GESP 2024-12 6 级 T2 · 闯关

- [B3996 闯关](https://www.luogu.com.cn/problem/B3996) 🟧
- **思路**：DP / 记忆化搜索，状态 `dp[i][j]` 表示到第 i 关血量 j 是否能通关
- **林展骥目标**：40 min 内 AC（重点是 DP 数组第二维是"血量上限"，不是关数）
- **林珅熠目标**：35 min 内 AC
- **复盘重点**：记忆化搜索写法 vs 递推写法都能过

## 附录 B：考前 1 页纸（4 模板）

### B.1 队列（约瑟夫）

```cpp
queue<int> q;
for (int i = 1; i <= n; i++) q.push(i);
int cnt = 0;
while (!q.empty()) {
    int x = q.front(); q.pop();
    if (++cnt == m) { cout << x << " "; cnt = 0; }
    else q.push(x);
}
```

### B.2 栈（括号匹配）

```cpp
stack<char> st;
for (char c : s) {
    if (c == '(') st.push(c);
    else if (c == ')') {
        if (st.empty()) { cout << "NO"; return 0; }
        st.pop();
    }
}
cout << (st.empty() ? "YES" : "NO");
```

### B.3 BFS 八方向

```cpp
int dx[8] = {-2,-2,-1,-1, 1, 1, 2, 2};
int dy[8] = {-1, 1,-2, 2,-2, 2,-1, 1};
queue<pair<int,int>> q; q.push({sx,sy}); dis[sx][sy] = 0;
while (!q.empty()) {
    auto [cx,cy] = q.front(); q.pop();
    for (int k = 0; k < 8; k++) {
        int nx=cx+dx[k], ny=cy+dy[k];
        if (nx<1||nx>n||ny<1||ny>m||dis[nx][ny]) continue;
        dis[nx][ny] = dis[cx][cy]+1;
        q.push({nx,ny});
    }
}
```

### B.4 0/1 背包

```cpp
vector<int> dp(V+1, 0);
for (int i = 1; i <= N; i++)
    for (int v = V; v >= w[i]; v--)
        dp[v] = max(dp[v], dp[v-w[i]] + v[i]);
cout << dp[V];
```
