📸 竞品分析与差异化策略：AI错题讲解机

1. 市场现状与竞品格局

通用搜索派 (夸克、百度)

核心玩法： OCR识别 -> 全网搜索 -> 直接给答案。

优势： 速度极快（3秒内），流量入口巨大。

劣势： 抄袭神器 缺乏讲解 容易引起家长反感，教育属性弱。

题库教辅派 (作业帮、快对)

核心玩法： 19亿题库比对 + AI解析 + 视频讲解。

优势： 内容权威，知识点覆盖全，技术壁垒高。

劣势： 大而全 重结果轻过程 依然以“展示解析”为主，缺乏个性化互动。

创新形态派 (阿里AI眼镜、101学问宝)

核心玩法： 硬件语音实时播报 / 真人教师解答。

优势： 交互新颖解放双手 / 真人解答准确率极高。

劣势： 硬件门槛 响应慢/成本高 难以大规模低成本复制。

2. 我们的定位 (AI-MATH-MISTAKE)

🤖 启发式 AI 错题互动课堂 (聚焦 4-6 年级数学)

我们不直接给答案，而是将“错题”转化为一堂“个性化微课”。

家长主导闭环 重推导过程 多端TTS语音播报 动态白板推演 沉淀为PPTX课件

3. 差异化竞争策略 (核心护城河)

  • 策略一：从“搜答案”到“启发式互动微课” (反抄袭设计)
    竞品一拍就出答案，家长非常抵触。我们的流程是：拍题 -> AI分析错因 -> 不给答案，先用语音(TTS)反问孩子 -> 引导孩子在动态白板上一步步推导。我们将产品包装为“家长的辅导帮手”，而非“孩子的抄作业神器”。
  • 策略二：极致的“家长管控与数据沉淀”生态
    我们的系统是基于“家长主账号 -> 孩子档案”设计的。孩子只能在受控环境（如平板的特定模式）下看微课，家长端能看到详细的《错因诊断报告》和知识漏洞，这打中了中国家长的核心痛点。
  • 策略三：深耕垂类（4-6年级数学）打磨体验
    放弃K12全科的贪大求全，只做4-6年级数学。这个阶段数学开始抽象，家长辅导最吃力。我们在此垂直领域将 Prompt 调优到极致，实现最精准的“进位、退位、运算顺序、概念理解”错因诊断。
  • 策略四：数字资产化（导出PPTX与实体打印）
    这是我们独有的 OpenMAIC 能力。错题解析可以直接生成 PPTX 或打印成 PDF，方便期末复习时直接形成实体“专属错题本”，这是纯线上 APP 难以提供的物理安全感。
