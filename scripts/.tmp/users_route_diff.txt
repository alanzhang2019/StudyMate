    fix(admin): /admin/users 报 Application error + bind mount classrooms 目录
    
    /api/admin/users: 把 select._count.select.profiles 改成
    select._count.select.studentProfiles。
    原因: lib/db.ts PrismaCompatClient.user.findMany 只识别
    studentProfiles, 用 profiles 会让 _count 变 undefined,
    UI 访问 u._count.profiles 抛 TypeError 把整页客户端树炸掉。
    现在 db.ts 看到 studentProfiles 后, 改写为
    { _count: { profiles: <n> } } 暴露给调用方。
    
    app/admin/error.tsx (新增): Next.js 错误边界。
    任何 /admin/* 子页面 throw 时, 不再让整页 'Application
    error', 而是渲染一个带错误消息 + '重试/返回 Dashboard'
    按钮的卡片, 侧栏 nav 仍可用, 学生/老师可以继续操作。
    
    docker-compose.yml: frontend.volumes 加 bind mount
      ./frontend/data/classrooms:/app/data/classrooms
    named volume 仍保留, 装 SQLite db + 其他持久化数据。
    新增/改名课件 JSON 后只需
      git pull && docker compose restart frontend
    不再需要 'docker cp' 手动同步。
